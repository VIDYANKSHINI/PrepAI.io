# Contributing to PrepAI.io

First off, thank you for considering contributing to PrepAI.io! It's people like you that make it such a great tool for everyone. 

## Code of Conduct

By participating in this project, you are expected to uphold our standards of professional and respectful behavior. We are committed to providing a welcoming and inspiring community for all.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please create an issue on GitHub. Include:
- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected behavior vs. actual behavior.
- Any relevant logs, screenshots, or system information (browser, OS).

### Suggesting Enhancements

We're always looking for ideas to improve! When suggesting a feature, please provide:
- A clear description of the proposed feature.
- Why it would be useful.
- Possible implementation ideas, if you have any.

### Pull Requests

We actively welcome your pull requests.

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure your code passes all linting and type-checking.
4. Update the documentation (README.md, comments) if applicable.
5. Create a Pull Request with a clear description of the changes.

## Development Setup

To get your development environment set up:

1. **Prerequisites**: Ensure you have Node.js 18+ and `pnpm` installed.
2. **Clone**:
   ```bash
   git clone https://github.com/VIDYANKSHINI/PrepAI.io.git
   cd PrepAI.io
   ```
3. **Install Dependencies**:
   ```bash
   pnpm install
   ```
4. **Run the App**:
   ```bash
   pnpm dev
   ```
5. **Linting and Type Checking**:
   Before committing, ensure your code is clean by running:
   ```bash
   pnpm lint
   ```

## Commit Message Guidelines

We prefer clear, structured commit messages. A good practice is to use conventional commits:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `style:` for formatting, missing semi-colons, etc.
- `refactor:` for code refactoring
- `test:` for adding or updating tests
- `chore:` for updating build tasks, package manager configs, etc.

*Example*: `feat: add real-time facial expression tracking`
